Each manifest entry retains the dataset, config/split/row, AMI audio ID, meeting ID, speaker ID, source interval, unchanged source text and SHA256 of the downloaded viewer WAV. The committed WAV has its own checksum. Signed delivery URLs expire and are regenerated by `evaluate.py fetch`; the checksum/identity must still match.

Changes made by this redistribution: selected already-segmented public IHM utterances; converted the dataset viewer's float WAV samples to mono **16 kHz signed PCM16** via ffmpeg; authored separate intended-clean targets and lexical meaning-protection predicates. No raw reference transcription was silently cleaned. The replay's optional energy-tail trim is labelled and recorded; committed natural audio is not energy-trimmed, amplified or synthetically filled. Scenario meetings such as TS3003 use fictional design-team roles and the company name Real Reaction, but the audio is **human, naturally spoken meeting interaction**, not generated speech.

Keep this attribution, source links, license link and change notice with copied AMI fixtures. CC BY 4.0 permits redistribution/adaptation, including commercial use, with attribution; it does not imply endorsement by the speakers or AMI Consortium. These public recordings do not grant rights to unrelated private speech.

## Synthetic domain-name and dictionary extras

Files: `audio/domain-*.wav`, `audio/negative-*.wav`, `audio/replacement-*.wav`.

These files are **deterministic synthetic speech**, generated for Pi Stack with eSpeak NG **1.52.0**, `en-gb`, 155 words/minute. The exact text recipe and generator declaration are in each manifest entry and `synthetic.py`. They contain no voice clone or recorded personal dictation. References are the text recipe, not a claimed human transcript or natural-speech gold.

The authored synthetic audio, text recipes, intended targets and curation metadata are dedicated by this repository to the public domain under **CC0 1.0 Universal**:

- Summary: https://creativecommons.org/publicdomain/zero/1.0/
- Legal code: https://creativecommons.org/publicdomain/zero/1.0/legalcode

The eSpeak NG program is a separately licensed GPL-3.0-or-later tool; it is not bundled here. Generating audio does not incorporate its program source/binary into these fixtures. Tool/project: https://github.com/espeak-ng/espeak-ng. ffmpeg is likewise an external conversion dependency, not bundled code.

`evaluate.py`, tests, scripts, documentation and baseline result receipts use the Pi Stack repository's software license. AMI-derived audio/transcript data and its clean-target annotations remain CC BY 4.0 regardless of the surrounding code license. Authored synthetic data is CC0 as above. No blanket software-license assertion is made over third-party recordings.

## Considered but not redistributed

- AMAAI Lab DisfluencySpeech / Nyra reformulation: Apache-2.0 dataset declarations, but a **single human speaker's studio reenactments** of Switchboard-derived utterances, not natural spontaneous recording. Existing project test/validation probes are not pristine holdout. Dataset description: https://huggingface.co/datasets/amaai-lab/DisfluencySpeech/blob/main/README.md.
- GigaSpeech: its software repository's Apache license does **not** license every underlying podcast/YouTube recording. No such audio was copied.
- VoxPopuli: an alternative public European Parliament corpus, but the aligned parliamentary references may omit natural disfluencies. No such audio was copied.

License declarations and source descriptions were checked on 2026-10-03 through the official AMI site and public dataset cards. Downloading remains bounded to the fixture clips; no whole-corpus mirror, gated/private data, or private folder content is included.
