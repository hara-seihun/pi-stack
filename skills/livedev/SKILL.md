## Live Dev
This is a live dev session, this means that you are not to run more than a few dozen tools at a time, and they should be mostly for reading and writing. You are not to write tests, you are not to check if something is working, you are to make modules live refresh as fast as possible and whatever the user is checking should be the current state of what you are working on with the user. You are not to write documentation, this will be done in another session, including the testing, and all other things not necessary to implement behaviour the user can interact with.
